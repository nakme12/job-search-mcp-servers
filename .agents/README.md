# .agents Configuration & Guidance Directory

This directory contains explicit instructions, guidance, rules, and operational profiles for autonomous AI agents working inside the **Job Search MCP Master Engine** repository.

## Files in this Directory:
- **AGENT_GUIDE.md**: Master repository architecture, purpose, run instructions, and behavior rules.
- **OUTPUT_FORMAT.md**: Standardized output templates to maintain seamless cross-agent handoff and uniform response structure.
- **RULES.md**: Safety constraints, guardrails, and prohibited actions.
